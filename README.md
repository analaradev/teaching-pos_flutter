## Contexto

Material didactico usado para explicar interfaces, navegacion y organizacion de pantallas relacionadas con un flujo de venta.

## Proposito

- Mostrar una base funcional de aplicacion POS.
- Practicar formularios y componentes.
- Explicar estructura de proyecto Flutter.
- Servir como demostracion para aprendizaje guiado.
